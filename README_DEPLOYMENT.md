## 手动启动和测试步骤

### 步骤 1：启动后端服务

打开命令行窗口（PowerShell 或 CMD）：

```bash
cd student-score-backend
./mvnw spring-boot:run
```

**等待启动完成**（约 30-60 秒），看到以下日志表示成功：
```
Started StudentScoreBackendApplication in X seconds
```

**验证后端：** 在浏览器访问 http://localhost:8080/health

应该看到：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "status": "UP"
  }
}
```

### 步骤 2：启动前端服务

打开**另一个**命令行窗口：

```bash
cd student-score-frontend
npm run dev
```

前端服务将在 http://localhost:5173 启动

### 步骤 3：访问系统

在浏览器打开：**http://localhost:5173**

## 常见问题

### Q1: 后端启动失败
**A:** 检查端口 8080 是否被占用：
```bash
# Windows
netstat -ano | findstr :8080

# 如果被占用，结束进程或更改端口
```

### Q2: 前端无法连接后端
**A:** 确保后端已启动并检查 API 代理配置（vite.config.js）

### Q3: 数据丢失
**A:** H2 内存数据库，重启后数据会丢失。这是预期行为。

### Q4: 批量保存失败
**A:** 检查：
- 学科和考试类型是否已配置
- 学生是否存在
- 成绩范围是否在 0-100
